## Описание

Модуль отображает соседей LLDP в разделе **Мониторинг → Топология LLDP**. Он использует узлы сети, связанные с шаблоном **Lldp Discovery**, и последние значения элементов `lldp.remote.info[*]`. На схеме SVG устройства показаны окружностями, а связи — линиями.

## Возможности

- В списке отображаются узлы, привязанные к шаблону LLDP, и их группы. Можно выбрать все группы и узлы либо ограничить область запроса.
- Данные загружаются при нажатии **Запросить**.
- На схеме локальные устройства расположены слева, удалённые — справа. При наведении видны устройства, порты и время последнего обновления.
- Статистика включает количество узлов сети, связей, устройств и пропущенных элементов данных.
- В JSON узла зарезервировано поле `image` для значков устройств.

Интерфейс поддерживает китайский, английский и русский языки. Чтобы включить русский, выберите **Русский** в профиле Zabbix. При выборе языка по умолчанию используется системная настройка `default_lang`.

## Установка

### Размещение модуля

```bash
# Zabbix 6.0 / 7.0
git clone https://github.com/X-Mars/zabbix_modules.git /usr/share/zabbix/modules/

# Zabbix 7.4 / 8.0
git clone https://github.com/X-Mars/zabbix_modules.git /usr/share/zabbix/ui/modules/
```

### Манифест для Zabbix 6.0

Для Zabbix 6.0 измените `manifest_version` на `1.0`. Для Zabbix 7.0 и 8.0 используется `2.0`.

```bash
sed -i 's/"manifest_version": 2.0/"manifest_version": 1.0/' zabbix_lldp/manifest.json
```

### Включение модуля

1. Откройте **Администрирование → Общие → Модули**.
2. Нажмите **Сканировать каталог**.
3. Найдите и включите **Zabbix LLDP Topology**.
4. Обновите страницу и откройте **Мониторинг → Топология LLDP**.

## Примечания

- Если шаблон не найден, проверьте `template_name` в `data/config.json`.
- Элементы с пустым `lastvalue` или значением, отличающимся от формата `DEVICE(PORT)`, пропускаются и учитываются в статистике.
- Имена удалённых устройств берутся из LLDP и могут отличаться от имён узлов сети в Zabbix. Устройства с одинаковым именем объединяются в один узел схемы.
- Значки устройств, силовая раскладка, объединение двунаправленных связей и вывод `REMOTE_SYS_DESC` в подсказках находятся за рамками версии 1.

### Владелец каталога и ошибки сохранения

Если владелец или группа каталога отличаются от учётной записи, под которой работает PHP, на странице модуля появится команда для изменения владельца. В сообщении об ошибке сохранения будут подсказки о правах на каталог и проверке SELinux командой `getenforce`.

## Настройка

### Шаблон LLDP

По умолчанию используется шаблон **Lldp Discovery**. Правило низкоуровневого обнаружения должно создавать элементы с ключом `lldp.remote.info[{#LOCAL_PORT}]`. Последнее значение элемента ожидается в следующем формате.

```
REMOTE_DEVICE(REMOTE_PORT)
```

Например, `YJZHZX-LouCengHuiJu-S7510E(GigabitEthernet2/2/0/1)`.

Свяжите шаблон с узлами сети, которые должны появиться на схеме, и проверьте, что обнаруженные элементы получают свежие данные.

### Файл конфигурации

Параметры хранятся в `data/config.json`.

```json
{
    "template_name": "Lldp Discovery",
    "item_key_prefix": "lldp.remote.info",
    "discovery_key": "lldp_discovery"
}
```

| Поле | Назначение |
| --- | --- |
| `template_name` | Видимое имя шаблона. При поиске также проверяется техническое имя. |
| `item_key_prefix` | Префикс ключа элементов с данными о соседях LLDP. |
| `root_hostid` | Необязательный ID узла сети Zabbix. Если узел есть на схеме, он используется как корень. |
| `discovery_key` | Ключ правила низкоуровневого обнаружения, зарезервирован для будущего использования. |

### Использование

1. Откройте **Мониторинг → Топология LLDP**.
2. Выберите группу и узел сети. По умолчанию выбираются все группы и узлы.
3. Нажмите **Запросить**.
4. Наведите указатель на связь или узел для просмотра сведений об устройствах и портах.
