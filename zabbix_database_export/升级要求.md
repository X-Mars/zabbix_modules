# zabbix 数据库导出模块

## 功能介绍

1. 该模块可以借用当前 zabbix web 设置的 mysql 的用户名和密码，直接导出 zabbix 数据库的所有表结构和数据，生成一个 sql 文件，500MB 内的sql文件直接页面下载，大于 500MB 的sql文件自动保存在用户的指定目录，推荐是/tmp/zabbix/。
2. 用户可以自定选择要导出的表，或者导出所有表。
3. 用户可以在数据表选择页面看到每个表的大小。
4. 用户可以选择导出数据表的结构和数据，或者只导出结构，或者只导出数据。
5. 该模块支持 zabbix 7.0、8.0。
6. 该模块支持 Mysql 和 PostgreSQL 两种数据库
7. 该模块可以在 zabbix web 页面直接下载导出的 sql 文件，也可以选择将 sql 文件保存到 zabbix 服务器的指定目录。
8. 只有 zabbix 管理员用户才可以使用该模块。
9. 该模块支持中英文。
10. 请将模块修改为 zabbix 数据库导出模块
11. 模块需要自动识别 zabbix 数据库类型，mysql 或者 postgresql，自动选择导出方式。请注意，页面上要展示数据库的版本好。

## 开发指引

1. 你可以参考 zabbix_cmdb 的代码，包括 php 方法的使用、中英文的实现。
2. 导出的 sql 文件名，以当前用户的时区时间为准，格式为：zabbix_backup_yyyy-mm-dd_hh-mm-ss.sql。
3. 你开发的所有功能，必须经过严格测试。
4. 整个模块的所有前端组件样式、配色、ui，你需要严格参考 https://element-plus.org/zh-CN/component/overview.html ，请注意不是直接引用，而是参考其样式和配色，进行仿写。
5. 每一次修改后，都通过将代码更新到两台测试服务器
