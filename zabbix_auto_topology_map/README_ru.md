## Описание

Модуль обнаруживает связи между сетевыми устройствами по данным LLDP, CDP и EDP, полученным по SNMP. Карты открываются в разделе **Мониторинг → Автоматическая карта топологии**. Модуль использует штатный API Zabbix и общие данные с разделом **Мониторинг → Карты сети**.

## Возможности

- Создание, поиск, сортировка, переименование, массовое удаление карт и экспорт в JSON.
- Обнаружение из узлов с интерфейсом SNMP. Глубина от 1 до 10 уровней, по умолчанию 3. Можно включить устройства вне мониторинга. Поддерживаются автоматические значки, построение дерева и несколько физических соединений между одной парой устройств.
- Повторное обнаружение обновляет устройства и связи. Модуль по возможности сохраняет существующие элементы, метрики и маршруты. Можно перестроить карту или сохранить позиции.
- Редактирование узлов, изображений, прямоугольников, эллипсов, линий и связей. Для связей доступны автоматические кривые, прямоугольные маршруты с обходом препятствий и ручные точки.
- Для пропускной способности, входящего и исходящего трафика можно назначить несколько числовых элементов данных. Последние значения суммируются и выводятся в подходящих единицах.
- Связь меняет цвет при срабатывании сопоставленного триггера. Сопоставление может быть автоматическим или ручным. Агрегированные связи используют общие подписи и настройки маршрута.
- Отображение нормальных, проблемных, обслуживаемых и отключённых узлов. Для фигур и узлов доступны макросы `{MAP.NAME}`, `{HOST.NAME}` и `{HOST.CONN}`.
- В режиме просмотра состояние и метрики обновляются раз в 60 секунд. Во время редактирования и при скрытой странице обновление приостанавливается.
- Из штатного меню узла доступны проблемы, последние данные и графики. Модуль запоминает последний режим просмотра, поддерживает масштабирование и вписывание карты в окно.
- Светлая и тёмная темы.

Интерфейс поддерживает китайский, английский и русский языки. Чтобы включить русский, выберите **Русский** в профиле Zabbix. При выборе языка по умолчанию используется системная настройка `default_lang`.

## Установка

### Размещение модуля

```bash
# Стандартный путь в Zabbix 6.0 / 7.0
git clone https://github.com/X-Mars/zabbix_modules.git /usr/share/zabbix/modules/

# Стандартный путь в Zabbix 7.2+ / 7.4 / 8.0. Совместимость необходимо проверить отдельно.
git clone https://github.com/X-Mars/zabbix_modules.git /usr/share/zabbix/ui/modules/
```

Можно скопировать только каталог `zabbix_auto_topology_map` в каталог модулей. Разместите `manifest.json` непосредственно в каталоге модуля и предоставьте веб-серверу доступ на чтение.

### Манифест для Zabbix 6.0

Для Zabbix 6.0 установите `manifest_version` равным `1.0`.

```bash
# Выполните из корня репозитория.
sed -i 's/"manifest_version": 2.0/"manifest_version": 1.0/' zabbix_auto_topology_map/manifest.json
```

### Включение модуля

1. Откройте **Администрирование → Общие → Модули**.
2. Нажмите **Сканировать каталог**.
3. Найдите и включите **Zabbix Auto Topology Map**.
4. Обновите страницу и откройте **Мониторинг → Автоматическая карта топологии**. Прямая ссылка действия — `zabbix.php?action=topomap.view`.

## Примечания

- Видимость карт и узлов определяется разрешениями Zabbix. Для создания, изменения и удаления карт требуется право `actions.edit_maps`.
- Изменения в любом редакторе применяются к общей карте. Перед редактированием можно выгрузить резервную копию в JSON. Импорт JSON через модуль не предусмотрен.
- Элементы данных для трафика и пропускной способности выбираются вручную. По умолчанию доступны числовые элементы узлов на двух концах связи. Отсутствующее значение отображается знаком `-`.
- Для автоматической привязки триггеров укажите по одному ключевому слову состояния порта на строку. Например, `link down`. Подбирайте слова к фактическим названиям триггеров.
- При повторном обнаружении по умолчанию сохраняются устройства и связи, которые не удалось обнаружить. Устаревшие автоматические связи можно удалить. Ручные связи сохраняются.
- В крупной сети начните с нескольких исходных узлов и небольшой глубины. Ограничения доступа, тайм-ауты SNMP и выключенные протоколы обнаружения могут сделать результаты неполными.
- Размер холста рассчитывается по содержимому. Холст расширяется во все стороны при перемещении элементов.
- Группы узлов, триггеры и вложенные карты можно просматривать, перемещать и удалять. Их свойства меняются в штатном редакторе. Статус рассчитывается для элементов типа «узел сети».
- В предпросмотре поддерживаются `{MAP.NAME}`, `{HOST.NAME}` и `{HOST.CONN}`. Для `{HOST.CONN}` используется основной интерфейс, затем IP-адрес или DNS интерфейса SNMP. Для правил сопоставления значков и остальной подстановки макросов используйте штатную страницу карт Zabbix.
- Перед обновлением сохраните данные карт и таблицы модуля. После обновления перезагрузите страницу через `Ctrl+F5` и проверьте OPcache PHP, если меню не обновилось.

### Владелец каталога и ошибки сохранения

Если владелец или группа каталога отличаются от учётной записи, под которой работает PHP, на странице модуля появится команда для изменения владельца. В сообщении об ошибке сохранения будут подсказки о правах на каталог и проверке SELinux командой `getenforce`.

## Разработка

- `manifest.json` и `Module.php` — конфигурация, маршруты и меню.
- `actions/TopomapView.php` и `views/topomap.view.php` — загрузка страницы и диалоги.
- `actions/TopomapData.php` — операции с картами, результаты обнаружения и сохранение метрик и маршрутов.
- `services/LldpDiscovery.php` — обнаружение соседей SNMP, обработка портов и сопоставление устройств.
- `lib/LanguageManager.php` — локализация.
- `assets/js/topomap.js` и `assets/css/topomap.css` — список, холст, редактирование и оформление.

Содержимое карты сохраняется через API `map`. Метрики, маршруты и настройки сохраняются в собственных таблицах. При изменении кода сохранения учитывайте повторное использование ID элементов и связей и удаление связанных настроек.

Сведения о расширении модуля см. в [документации по разработке модулей Zabbix](https://www.zabbix.com/documentation/7.0/en/devel/modules).

## Настройка обнаружения

- Установите расширение `snmp` для PHP, который обслуживает веб-интерфейс Zabbix. Для обнаружения достаточно расширения PHP.
- Проверьте доступность устройств с сервера веб-интерфейса по SNMP и включите на устройствах нужные протоколы LLDP, CDP и EDP.
- Добавьте интерфейсы SNMP и параметры аутентификации в Zabbix. В качестве исходных можно выбрать только узлы с интерфейсом SNMP.
- Учётной записи базы данных веб-интерфейса нужны права на создание, чтение и запись таблиц `topomap_link_metrics`, `topomap_link_paths` и `topomap_settings`. Модуль создаёт их по мере необходимости.

Установите пакет для вашей ОС.

```bash
# Debian / Ubuntu
sudo apt update
sudo apt install php-snmp

# Системы с dnf (Rocky Linux, AlmaLinux, Fedora)
sudo dnf install php-snmp

# Системы с yum (старые выпуски CentOS и RHEL)
sudo yum install php-snmp
```
